4 · Escape 保留前文

5 · 中间编辑

6 · Forward Delete（人工项）

待观察

清空后输入 nihao，确认光标在末尾，按实体键盘的 Forward Delete（通常为 Fn+Delete）。它不应像退格一样变成 niha。

Forward Delete 的最终组合状态交由用户观察；本页不会伪造 PASS。

7 · 组合 Return 与空闲 Return

待观察

清空后输入 nihao，按一次 Return，再按一次 Return。第一次应提交原始 nihao 且不换行；第二次才插入一个换行。

检查器会记录第一次 Return 后的文本快照。
